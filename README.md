# Aplus Technology Solutions - B2B Website

This is a modern, responsive B2B website for a Samsung Commercial Display Distributor, built with [Next.js](https://nextjs.org) and [Tailwind CSS](https://tailwindcss.com).

## Features

- **Mobile & Tablet Compatible**: Fully responsive design with touch-friendly interactions.
- **Product Catalog**: Smart Signage, Video Walls, Interactive Displays.
- **Dynamic Routing**: Category and Product structure.
- **Quote Request System**: Integrated form for lead generation.
- **Interactive UI**: Hero sliders, animations (Framer Motion), and product galleries.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
The website is optimized for various screen sizes. To test mobile view:
- Open Chrome DevTools (F12)
- Click the "Toggle Device Toolbar" icon (Ctrl+Shift+M)
- Select a mobile device (e.g., iPhone 12, iPad Air)

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
