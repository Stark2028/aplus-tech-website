# Product Images Directory

This directory contains all product images organized by category.

## Structure

Each category folder contains subdirectories for individual products. Product images should be placed in their respective product folders.

## Adding Images

1. Create a folder for your product using kebab-case naming
2. Add images named `image-1.jpg`, `image-2.jpg`, etc.
3. See `docs/PRODUCT_IMAGES.md` for detailed guidelines

## Categories

- `smart-signage/` - Smart Signage displays
- `video-walls/` - Video Wall solutions  
- `interactive/` - Interactive displays
- `business-tv/` - Business TV models
- `hotel-tv/` - Hotel/Hospitality TV
- `touch-displays/` - Touch display products
